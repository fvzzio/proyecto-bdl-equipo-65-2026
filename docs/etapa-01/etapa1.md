# Equipo alegría (65)

## Rubro elegido: Comercio Minorista

## Alcance: Supermercado

Integrantes: Espindola Santiago Emanuel, Herrera Rodriguez Matias, Cuenca Luque

Fabrizio Lautaro, Demarchi Luana Flor, Enrique Ayelen Maria.

Un Supermercado minorista comercializa diferentes artículos y desea organizar la información relacionada con sus empleados, clientes, productos y proveedores. De cada empleado se desea conocer un código que lo identifique, DNI, nombre y apellido, número de teléfono y puesto laboral (Gerente, Cajero, etc…)

De cada cliente se desea conocer un código que lo identifique, DNI, nombre y apellido, número de teléfono. El supermercado comercializa diferentes productos. De cada producto se desea registrar un código que lo identifique, una descripción, precio de venta, tipo (lácteos, carnes, pastas…etc), y cantidad disponible en stock. Para llevar un registro de las operaciones realizadas, cada compra debe quedar registrada indicando la fecha en que se realizó, cantidad de unidades adquiridas de cada producto, precio unitario de cada producto. Los productos comercializados por la empresa son suministrados por diferentes proveedores. De cada proveedor se desea registrar un código de identificación, CUIT, dirección,

teléfono, y producto que provee.

## Reglas de negocio:

- RN1: una persona es considerada cliente incluso si no lleva productos.

- RN2: un/a empleado/a puede ser considerado cliente.

- RN3: una persona puede llevar más de un producto asimismo puede llevar más de un mismo producto.

- RN4: Un producto puede ser comprado por diferentes clientes.

- RN5: Cada compra llevan un Recibo/Factura (A, B).

- RN6: En cada recibo se detalla precio unitario y la cantidad que se lleva.

- RN7: En cada factura se detalla datos del cliente que realizo la compra, monto total de la compra, tipo de factura emitida, medio de pago, fecha y hora.

- RN8: Los clientes pueden tener varios métodos de pago (efectivo, transferencia, tarjeta, etc.)

- RN9: Un proveedor puede suministrar uno o varios productos y asimismo un producto puede ser suministrado por varios proveedores.

- RN10: Un cajero puede atender a varios clientes, pero un cliente puede ser atendido por un solo cajero.

- RN11: Una compra puede contener uno o más productos.
